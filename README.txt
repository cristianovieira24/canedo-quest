Canedo Quest v8 — plataforma de reforço para o concurso de Designer Gráfico da Câmara de Senador Canedo.

Escala atual: 106 módulos teóricos, 473 questões autorais graduadas, 340+ flashcards, 318 exercícios de revisão ativa, provas de módulo, provas por matéria, simulados completos, maratona de 60 questões, revisão por erros/pontos fracos/24h+ e lousa.

Experiência guiada v8:
- A tela inicial mostra apenas o próximo passo recomendado.
- A trilha conduz o aluno por aulas em sequência, desbloqueando o próximo passo.
- Matérias e ferramentas secundárias ficam acessíveis em “Mais”, sem lotar a navegação principal.
- Botões e respostas têm microanimações e feedback sonoro opcional.
- O progresso, XP, sequência e erros continuam salvos no localStorage.

Abra index.html ou publique a pasta no GitHub Pages. O progresso pode ser exportado/importado.

PWA: esta versão pode ser instalada na tela inicial do celular. Abra pelo GitHub Pages; em navegadores compatíveis use o botão “📲 Instalar”. O aplicativo também registra um cache offline dos arquivos principais.
